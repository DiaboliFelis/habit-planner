# ТЗ: Фича «Дневник настроения»

## 1. Цель фичи
Добавить возможность отслеживать эмоциональное состояние пользователя и выявлять связь между выполнением привычек и настроением.

## 2. Happy Path
1. Пользователь заходит в раздел «Сад привычек».
2. Нажимает на кнопку «Как ты сегодня?» (или видит плашку «Отметь настроение»).
3. В модальном окне выбирает один из эмодзи: 😊 (хорошо), 😐 (нормально), 😔 (плохо).
4. Может добавить короткий комментарий (опционально).
5. Нажимает «Сохранить».
6. Запись сохраняется в базе. Если он уже отмечал настроение сегодня, запись обновляется.

## 3. Отображение (UI)
- **В Саду:** небольшая плашка под шапкой (если настроение не отмечено сегодня, она яркая; если отмечено — показывает выбранный эмодзи).
- **В Альманахе:** 
  - График (столбчатая диаграмма) настроения за последние 7 дней.
  - Блок «Инсайт»: сравнение процента выполненных привычек в дни с хорошим и плохим настроением.
